# Public Copy Style Guide

Popular Consensus should feel calm, trustworthy, and easy to use. The product can do technically advanced things, but the first words a user sees should describe ordinary actions in ordinary language.

## Voice

- Clear before clever.
- Friendly without sounding casual about serious decisions.
- Light, direct, and useful.
- Confident, but never grandiose.
- Human first, protocol second.

## Preferred Words

Use these words in the public UI:

- ask a question
- review a question
- flag wording
- open voting
- get a voting pass
- cast a private vote
- count votes
- post results
- public receipt
- saved record
- community signal
- next-step rule
- rewards
- report
- approved customer
- claim reward

Avoid these words in primary UI labels unless a plain explanation appears nearby:

- registry
- artifact
- nullifier
- credential schema
- tally
- attestation
- adoption policy
- quorum
- steward
- curator
- settlement
- protocol

## Translation Rules

| Technical term | Public copy |
| --- | --- |
| poll | vote or voting |
| tally | count votes |
| artifact | receipt, record, or proof |
| registry | public record or question list |
| credential | voting pass |
| authority level | what happens next |
| advisory | community signal |
| recognized | guides a real next step |
| binding | committed decision |
| data union | rewards or rewards system |
| aggregate product | privacy-safe report |
| buyer | approved customer |
| settlement | payment |
| steward or curator | community guide |
| challenge | flag |

## UI Pattern

Lead with the action, then explain the trust layer only when needed.

Good:

> Get a voting pass, then cast one private vote.

Avoid:

> Issue a credential and submit a nullified encrypted ballot.

Good:

> Votes counted. The public result receipt is posted.

Avoid:

> Tally complete and result artifact published.

## Trust And Safety Copy

When explaining proof, start with the user benefit:

- "This receipt lets anyone check the result."
- "Votes are counted together. Individual answers stay private."
- "This record shows what changed and when."

Then, if needed, show hashes, replay checks, or protocol identifiers as supporting detail.

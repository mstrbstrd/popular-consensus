The Solidity events already cover most lifecycle edges, and `@pc/replay` now includes an onchain event adapter plus `pc-replay verify-chain` for the grant-critical subset. ## Contract Alignment Work

The adapter lives at `packages/replay/src/onchainEventAdapter.ts`, and the RPC wrapper lives at `packages/replay/src/verifyChain.ts`. Unknown onchain event names fail replay adaptation instead of being silently ignored. The local-chain transcript is generated by `pnpm grant:chain-replay`. Contract-side coverage lives in `testFullProtocolLifecycleEmitsReplayableEvents`, which records Solidity logs and asserts each grant-critical event has the expected emitter, signature, indexed subject, topic count, and data payload length.

## What Other Builders Can Reuse

The event table gives external builders a checklist for the minimum event stream needed to rebuild a civic decision record from public evidence.
